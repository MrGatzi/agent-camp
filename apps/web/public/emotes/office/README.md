# Office emotes

Six original static 12×12 pixel drawings authored for the office-chat feature (2026-11-12), exported as 24×24 same-origin SVGs. No third-party artwork, fonts, scripts, animation, embedded images or remote references. They use the office's warm pixel palette and follow this repository's license terms.

Tokens: `:campfire:`, `:coffee:`, `:wave:`, `:shipit:`, `:thinking:`, `:party:`. The text tokens are the storage/wire format; older clients and Mac notifications keep the literal names. The chat's Text names option and failed-image fallback do the same.
